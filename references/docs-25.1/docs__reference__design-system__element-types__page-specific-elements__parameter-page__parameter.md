
# Parameter

## About
Example Parameter with a label and two
Magic Input.A parameter is a set of inputs and outputs that are used together to adjust
a specific setting of a machine. It includes a label that provides context
for the operators.

- LabelInput

## Element Properties
Display Condition

#### Condition
Determines whether an element or page should be visible or hidden to the current user. The condition can be set to different types of
Dynamic Property
– as long as the the type returns
true
or
false
you're good to go.

## Specific Properties

### General

#### Label
Provides context and information to operators, guiding them and helping them understand the value of this particular element. A good label instills confidence in operators when making adjustments.

#### Icon
This icon will be displayed next to the element's label on pages that support it, like the
Dashboard Page
. An Element can make use of the icon to...
- provide more meaning and improve recognition.

#### Legend
Use the legend to reference specific points of interest on visualizations,
such as images.
The legend can be an alphanumeric value but it is limited to two
characters.
For instructions on how to add such markers to your images,
refer to the
Image page.
To highlight a `Parameter` with a specific legend, use the
Highlight Legend on Current Page action.
