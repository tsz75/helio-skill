
# Define Placeholders for Lists
- Create a list
- Locate the HMI Data Explorer in the Data View and right click the `Data` folder.
- Choose Add List > List of Objects.
- Activate placeholders
- Activate the `Placeholder` property of the list.
- Set the `Item count` to the desired amount of items you’d like to simulate.
- Define the blueprint for list items
Define the shape of the items in this collection like by defining its
`Item Blueprint`.Add variables and choose appropriate types for your use case:[img:]
- Define Placeholders for each item in the blueprint
- Select a property of the Item Blueprint.
- Active the Placeholder for this property.
- Add one ore multiple placeholders.
- Use it in your HMI
Switch to the Content View and activate Placeholder Mode.
If you haven’t done so already, link your list to a collection page now.
Mission accomplished!
Your list will now contain simulated items using the placeholders you just
defined! 🎉
