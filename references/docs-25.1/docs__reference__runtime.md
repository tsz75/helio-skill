
# HELIO Runtime
HELIO ships in the form of a small and efficient web server – the
so-called
HELIO Runtime.
- It is the only piece of software that needs to run on your target devices
or
on your development PC.
- Both the
HMIs as well as the
HELIO IDE are web applications served by the runtime, so
any
computer or device with a supported browser
 can execute them.
- It's also the only component that communicates with the machine control
layer and
the data sources, making their data and functionality available to its
clients
using HTTP based APIs.
