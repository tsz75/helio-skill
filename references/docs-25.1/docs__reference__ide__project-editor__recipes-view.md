
# Recipes View

## About
Use the `Recipes View` to define your machine's `Recipe Types` and add
ingredients to those recipes using the data model you have setup in the
Data View.
- List of all recipe types.Use the `Add` button to create new recipe types.List of all recipe parameters for the selected recipe type.Use the `Add` button to add new parameters to the recipe type.Set the restrictions for the recipe type.
