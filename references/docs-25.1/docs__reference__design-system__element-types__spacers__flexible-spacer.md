
# Flexible Spacer

## About
Adds a flexible space between two elements that will occupy maximum space.

## Element Properties
Display Condition

#### Condition
Determines whether an element or page should be visible or hidden to the current user. The condition can be set to different types of
Dynamic Property
– as long as the the type returns
true
or
false
you're good to go.

## Specific Properties

### Sizing

#### Spacer Width
Decide if the spacer should be flexible or fixed-size. Flexible spacers
occupy all the available space, whereas fixed spacers utilize a specified
amount of pixels.
