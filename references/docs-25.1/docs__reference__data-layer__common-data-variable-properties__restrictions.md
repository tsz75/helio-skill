
# Restrictions
You can restrict access to HMI
Data Variables from within the
HMI Data Explorer. This ensures that these
restrictions are applied to all pages and elements that use the variable.
You can restrict either the reading or writing of variable values. In both
cases, you can choose between...
**Allow everyone:** action can be executed by anyone, including anonymous users.
**Do not allow:** action is prohibited for everyone.
**Allow only:** action is allowed, but only for the groups you explicitly specify.
