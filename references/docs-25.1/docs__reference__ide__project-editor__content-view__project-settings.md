
# Settings View
The `Settings View` is the central location for all settings that affect the
entire project.
←
→
The `Settings View` will help you set the basics of your HMI: Select which
devices your HMI should be previewed on, set a description for your project,
choose what you want your HMI to look like and much more.

## Sections
General Settings
Devices Settings
Internationalization Settings
Authentication & Security Settings
Style: Look & Feel
Extensions
Messaging Settings
Audit Trail Settings
Heartbeat Settings
