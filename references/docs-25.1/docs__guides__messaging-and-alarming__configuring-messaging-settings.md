
# Configure Messaging Settings
First, let's take a look at the overarching
Messaging Settings that apply to all
messages.
- Locate the Messaging Settings
You'll find these settings in the Project Settings
section of the Content View.
- Make Sure All Messages Open as Dialogs
The `Display Options` group lets you decide how HELIO should show a
message to your operators. You can simply add it to the list
of active messages or display it as a dialog that prompts operators to
pause their current task.You can do this for each level type. For now, we'll choose to show all the
