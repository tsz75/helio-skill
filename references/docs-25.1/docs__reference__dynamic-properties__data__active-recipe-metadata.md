
# Active Recipe Metadata

## About
Use this property to access the metadata of any recipe type like for
example the `Recipe Name` that was set by operators when saving, for example
on a Recipe Management Page.

### Recipe Type
Choose the recipe type of which you would like to access the metadata.

### Metadata

#### Name
The currently active recipe's name that was set while saving.

#### Created At
The time at which the currently active recipe was saved.

#### Created By
The person that saved the currently active recipe.
