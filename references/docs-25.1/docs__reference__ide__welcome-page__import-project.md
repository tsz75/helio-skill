
# Import a Project
So you have exported a project following the Export an Existing Project guide.
You can also drag & drop a `.helio` file anywhere onto the Home Page to import it directly — no need to click the `Import` button.
- Open the Home Page…
…and make sure you are signed in.
- Import your `.helio` file
Click the `Import` button at the top of the project list and select the `.helio` file.
