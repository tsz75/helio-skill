
# Placeholders for Offline Editing
You may often need to work on an HMI without access to the actual PLC.
However, you still want to be able to view the pages and elements of your
HMI as if they were populated with data.Use Placeholders to define values that will be displayed in
HMI Preview Panel when `Placeholder Mode` is active.
