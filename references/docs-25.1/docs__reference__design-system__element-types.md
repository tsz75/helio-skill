
# Elements
»`Elements` are the **basic building blocks** for your HMI, kind of **like
Lego blocks for your interface**.«Pretty much anything you can add to a Page is an
`Element`.
Think Dashboard Widget, Button, or a Gauge - yup, they're all elements. Each
element has
properties you can tweak and adjust to get it just right for your needs.
