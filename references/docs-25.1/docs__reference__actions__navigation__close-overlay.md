
# Close Active Overlay Action

## About
Use this action to close an overlay that the user has opened. It is typically
used on pages that have been opened as overlays using the Open Page as Overlay Action action.

## Examples

### Close an Overlay Using a Button
In this example, the primary button in the overlay will close the overlay.

### Save Data to the PLC and Then Close the Overlay
Pressing the primary button in this example will execute the
Execute Multiple Actions.By using this approach, we can inform our PLC of a user's decision by
writing some state to a variable. After triggering this action, we close the
overlay that was used to gather some additional information about the
decision.
