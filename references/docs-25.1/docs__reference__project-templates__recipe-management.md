
# Recipe Management
HELIO 24.2 introduced an integrated recipe management that significantly
streamlines the creation and integration of recipes into your HMIs.
Check out the this template to learn how to set up the basics of
a recipe management system.

## Using the Template
Use the `Create New` button on the
Welcome Page of the
HELIO IDE and you will be asked to choose a template for your
project.
