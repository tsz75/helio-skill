
# Pie Chart

## About
A pie chart is a good tool to show how different values relate to each
other. Each category is a slice of the pie, so you can see how big each
category is compared to the others. This way, operators can quickly grasp
the content of a dataset.

## Properties

### General

#### Label
Provides context and information to operators, guiding them and helping them understand the value of this particular element. A good label instills confidence in operators when making adjustments.

#### Icon
This icon will be displayed next to the element's label on pages that support it, like the
Dashboard Page
. An Element can make use of the icon to...
- provide more meaning and improve recognition.

### Slices
Add Slices to the Pie Chart and select a label, a value and a color for each.LabelProvides context and information to operators, guiding them and helping them
understand the meaning of the value of this particular element.ValueThe current value that should be displayed on the Slice, usually this will
be bound to a Data Variable Types.ColorChoose a unique color for each slice of the Pie Chart. This will help users
distinguish between different values.

### Chart Legend

#### Absolute Values
Display the actual values of each SecurityPolicyViolationEvent

#### Percentage Values
Display values as percentages

#### Display Total
Display total of all the slices at the bottom of the legend

### Display Condition

#### Condition
Determines whether an element or page should be visible or hidden to the current user. The condition can be set to different types of
Dynamic Property
– as long as the the type returns
true
or
false
you're good to go.
