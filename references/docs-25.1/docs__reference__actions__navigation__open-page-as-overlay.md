
# Open Page as Overlay Action

## About
This action allows you to open a floating overlay on top of your current
Page. Within this overlay, you can display any page
from your HMI. This is
possible because HELIO Pages are inherently responsive.This example action opens a page called `Dashboard`. The overlay will be
centered and faded in. Its size is set to `Full`, so it will take up the
full viewport of your current page.

## Properties

### Placement
Lets you place the overlay in the center or in the right half of the page.

### Size
Depending on the `Placement` property, you can assign different sizes.
Center 

Full
Medium
Small


Right 

Large
Medium
Small

### Animation
Lets you adjust the way the overlay will animate into the current page.
