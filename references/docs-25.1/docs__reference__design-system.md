
# HELIO Design System
The HELIO Design System is a set of elements that allow you to create
future-proof user interfaces for industrial machines.
It contains both generic and very specific Elements, Pages for controlling
industrial machines, as well as a navigational framework.
The primary tool to set up and create HMIs using this design system, the
HELIO IDE.
