
# How can I download an invalid project from a ctrlX device?

## Symptom
- After you made some changes to your project, HELIO marked it as invalid, and now you can't open it.
- Your welcome page looks something like this:

## Solution
- Download the invalid project from the app data directory like this:

←→
  - Use the `Manage app data` view to open the HELIO Data Directory.
  - Open the `projects` folder and look out for a `.json` with the name of your project
  - Download this json file to your development machine.
