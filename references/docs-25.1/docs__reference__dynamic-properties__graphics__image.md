
# Image

## About
The `Image` property allows you to upload and use image assets.

## Placing Markers
It is possible to attach Markers to uploaded images that highlight certain points of interest.
These Markers can then be referenced by other elements in your HMI.
For example Parameter on the Parameter Page can use the
a Parameter Page you can reference these markers
You can reach the `Place Markers` button by expanding the property. Clicking
this button opens the `Marker Editor` which lets you place Markers onto this
image.
