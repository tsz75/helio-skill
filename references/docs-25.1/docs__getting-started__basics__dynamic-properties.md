
# Dynamic Properties

## What Exactly Are Dynamic Properties?
Pages and Elements come with
properties that allow you to control their visual representation and their
behavior. For example you can manipulate the `Title` property of a page.
Some properties have an additional secret superpower:
you can change their types. Such a property is called a Dynamic Property.
Let's take a look at a concrete example to illustrate how this works.
From Static To Dynamic Page Title

## A Real-Life Example
- The `Title` of this page is currently using the type `Localizable Text`.
- HELIO renders this text inside the page title.
- Once you switch the type to `Data Variable`, you are able to link
it to a variable. In this case, we choose the variable
**`RecipeCount`**.
- In the preview, you can now see result of this change: the
number of overall recipes is now being displayed instead.
