
# Message Triggers View
The `Message Trigger` view is where you add rules to your project that
define when messages should show up in your HMI.

## Anatomy
- Use the `Add` button to create new triggers.Choose between different types of triggers. `Process Variable` being
one of the simpler types.`Dynamic Message` triggers are more complex but also offer more flexibility.Adjust the properties of the currently selected trigger.

## Learn More
Check out the Messaging & Alarming guide to learn
all the details about messaging.
