
# Number of Active Messages

## About
This property will display the number of
Active Messages.

## Properties

### Level
Select the message levels to be included in the calculation. HELIO will count
all active messages that have one of the selected levels set. This means that
multiple levels can be selected.

### Status
Lets you choose whether to include acknowledged or unacknowledged messages in
the calculation. Of course, you can also select both and count them all.
