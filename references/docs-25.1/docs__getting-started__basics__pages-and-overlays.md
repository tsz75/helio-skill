
# Pages & Overlays

## What Are Pages?
HELIO HMIs are structured using Pages, similar
to a web page. HELIO comes with a variety of Page Types,
with each page serving a specific purpose.

## Page Characteristics
- Operators can use HELIO's Navigation to move between `Pages`.
- Every `Page` you add to your HMI will be available in HELIO's
Navigation by default.
- You can restrict or disable a `Page`'s availability in the navigation.

## What Is an Overlay?
An `Overlay` is a container that floats in front of the current page.
It is usually used to accomplish a sub-task without loosing the context
of the current page.
Since HELIO is built with responsiveness in mind from ground up, every page
in your HMI can also be opened as an Overlay using
the  Open Page as Overlay Action.
Once the task is completed, the operator can close the overlay and return
to the page that originated it.
