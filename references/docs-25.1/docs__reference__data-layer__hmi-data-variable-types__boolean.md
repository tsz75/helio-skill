
# Boolean
A `Boolean` variable represents a binary state. It can have only two possible
values: `true` or `false`. It is often used to represent on/off states. Examples
include a button being pressed or a light being turned on or off.

## Define a Variable
- Open the Data ViewRight-click any folder in the HMI Data ExplorerChoose `Add Variable`Choose the type  Boolean
