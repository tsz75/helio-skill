
# Enable User Management in the HMI
You've learned how to restrict access in all kinds of ways, e.g. Restrict Access to Pages.
Now there is one topic left that we'll dive into: how to enable HMI users to manage HMI users.
- To customers manage their user own base, you can be simply add the User Management Page
to your HMI. Refer to the User Management Page documentation to see whats possible.
- You might want to restrict this page as well so not every HMI user will be able to manipulate and
delete HMI users.
