
# Property

## About
Use Properties on Collection Page
to display Lists.

## Element Properties
Responsive Behavior

#### Keep visible as long as possible
This option is mostly important for smaller displays where the element may need to shrink. Check this option for the most important children. They will then be kept withing the visible viewport as long as possible.
Display Condition

#### Condition
Determines whether an element or page should be visible or hidden to the current user. The condition can be set to different types of
Dynamic Property
– as long as the the type returns
true
or
false
you're good to go.

## Specific Properties

### General

#### Title
Provides context and information to operators, guiding them and helping them
understand the meaning of the value of column.-> Dynamic Property

### Data Source

#### Item Attribute
Choose the value from the list that you want to display in this column.

### Appearance
Choose whether to display the unit for this column within the header.Emphasize the most important column.

### Column Width
Decide if the column should have a fixed width or be sized in relation to
the other columns. Select either the fixed width in pixels or the weight and
minimum width in pixels.
