
# Message Types View
The `Message Types` view allows you to define the various message types
that can be sent to the operators. In addition to the `Message Code`, you can
also enter the detailed content, such as the description or a solution, that
will be displayed when the message is displayed on the HMI.

## Anatomy
- Use the `Add` button to create new messages types.Each type is defined by a unique `Message Code`.As well as a `Message Level`.The properties let you define the content of the message.
