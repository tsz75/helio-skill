
# Markdown

## About
Add text to your HMI that can be formatted using Markdown.

## Element Properties
Display Condition

#### Condition
Determines whether an element or page should be visible or hidden to the current user. The condition can be set to different types of
Dynamic Property
– as long as the the type returns
true
or
false
you're good to go.

## Specific Properties

### General

#### Content
Add the text you want to display and use all the ordinary Markdown features
to set headings, lists, links, etc.
