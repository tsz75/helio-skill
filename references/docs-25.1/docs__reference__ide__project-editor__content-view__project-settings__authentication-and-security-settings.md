
# Authentication & Security Settings
The `Authentication & Security Settings` let you customize the security details of
your HMI.

### Password Policy
Establish a set of rules that'll be enforced when HMI users create or change
their passwords.

#### Minimum password length
This is the minimum number of characters that HMI users must enter to create a valid password.

#### Require uppercase character
Turn this option on to require HMI Users to use capital letters in their passwords.

#### Require numeric character
Turn this option on to require HMI Users to enter numbers in their passwords.

#### Require special character
Enable this option to require HMI users to enter special characters, such as `#`, `@`, or `$`.

### On Sign in

#### On Success
Execute an action after a user has signed in successfully — for example
to Request Exclusive Control.
