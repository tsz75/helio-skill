
# Icon

## About
If an element does support to add icons this property will get used.
It lets you choose from the ever-growing list HELIO icons that come
prepacked with every HELIO instance.

## Icon Library
Clicking on `Select Icon` button opens the Icon Library which lets you search
an pick an icon in no time.**Tuned For Speed**Hunting for icons can be a real drag, but HELIO's got your back.
It makes finding the right symbol a matter of a few keystrokes.
Just start typing to use the search feature and quickly narrow down your options.
Use the Down and Up arrow keys to select an icon.
Use the Enter key to confirm the currently selected icon.
