
# Data View

## About
Use the `Data View` to connect to data sources, define PLC connections,
import PLC data into your project, and enhance it with valuable information
such as units, limits, or ranges.

## Sections

##

### HMI Data Explorer

## 
Lets you define the data model for your project. By shaping the data
appropriately, you can ensure that it best fits your HMI.

## Data Layer Fundamentals
HELIO is equipped with a
HELIO Data Layer that allows you to connect to different types
of data sources and abstract their data in a unified way within your project.

### Basic Data Types
The HELIO Data Layer provides a set of data types that
can be used to describe the variables in your project. HELIO can use this type
information to provide a better experience for your operators.
For example, when connected to a variable of a numeric type, a
Magic Input element will adjust itself to make it
easier to enter numeric values.
