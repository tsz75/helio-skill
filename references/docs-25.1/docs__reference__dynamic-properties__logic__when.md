
# When

## About
Use a `When` operator to solve a series of conditions. This could be simple
or more complex, depending on your needs.For example you might want to display something as soon as
multiple Condition are true.

## Anatomy
- **All or one**Select whether all conditions within the `When`
operator or only one of them need to be the value selected in **4**.**Conditions**Thees are the conditions within the `When`
operator. They each are a Dynamic Property so
choose whatever you need and make it as simple or complex as you need.**Add Condition**Add as many conditions as you need.**True or False**Select whether the condition(s) need(s) to be
true or false.
