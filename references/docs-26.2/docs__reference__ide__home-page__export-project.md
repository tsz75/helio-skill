
# Export an Existing Project
HELIO lets you export projects so you can transfer it between different machines
or computers.
- Projects will be exported as `.helio` files.
- You can also use this as a backup mechanism.
Open the Home Page…
…and make sure you are signed in.
- Open the `Options Menu` of the project
- Choose the `Export` option
- Choose content to be included
**Project data**
- All the settings and content of your HMI.
- All HMI variables and data are defined in your project.
**Data sources**
- Decide which Data Sources you would like to export.
- If you include a Data Source, it will be created during the import of the project
**Translations**
- If you check this option, it will export all the translations of
your current HELIO Runtime and include them in the export file.
- This process is effectively equivalent to manually exporting all
translations using the Translation Manager.
