
# URL Parameter Value
Use the value of a given URL Parameter.
In the example the value of the `panelLocation` URL parameter will be
displayed as the `Title` of the element.
This property can also be used to to show or hide elements within your
project if you use this dynamic property in combination with the
If Condition or a
Switch.
