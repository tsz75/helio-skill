
# HELIO Playground PLC
A Soft-PLC designed for testing and simulating HELIO HMIs using OPC-UA.
←
→
The HELIO Playground PLC is a software tool designed for your development machine, acting as a PLC simulator.
- It provides an API based on OPC-UA with sample variables.
- Use it to follow the getting started tutorials like Build Your First HELIO HMI Using the HMI-Driven Approach.
- Test your HMIs using OPC-UA when there is no PLC backend available for simple testing.
- Run and test HELIO Project Templates against a PLC backend.

## Running it
Just like HELIO, the HELIO Playground PLC is also a simple executable that you can
execute on your development machine.
Make sure that your firewall does not block the server!
