
# What Type of HMI Engineer Are You?

### HMI-Driven
- Do you like to work on the UX and HMI side of things?
- Do you like working with tools like Figma, Adobe UX, Sketch?
- Do you like to sketch your ideas using pen and paper?
- Is the PLC a black box for you?
**Then check out these resources:**
- Build Your First HELIO HMI Using the HMI-Driven Approach

### PLC-Driven
- Do you like to work on the backend part of industrial machines?
- Do you like working with realtime-related code on the PLC as close to the
metal as possible?
- Do you like to work with people that take care of the HMI stuff so that you can
concentrate on your PLC code?
