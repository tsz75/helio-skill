
# Define Message Types
In order to trigger and display messages, we first have to define them. You
use the `Message View` of the HELIO IDE to define message types that are
uniquely identified by their `Message Code`. For each type you can define
additional content, media, and actions that will be displayed when a message
with that code is triggered.
