
# Internationalization (i18n)
HELIO was built from the ground up with Internationalization in mind.
Internationalization, often abbreviated as `i18n`, is the process of designing and
developing applications, products, or services that can be adapted to various
languages and cultural norms without requiring changes to the source code.
The goal of internationalization is to create products that can be easily
translated into different languages and adapted to different cultures.
**It's Unicode All the Way Down**
HELIO uses Unicode to display a wide range of characters, making it possible
to work with languages that use non-Latin scripts.
