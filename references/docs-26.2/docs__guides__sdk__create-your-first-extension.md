
# Create Your First Extension
Time to build your first HELIO Extension. You'll create a traffic light indicator –
a colored circle that switches from green to red when a monitored value exceeds a
threshold.
You'll start with setup, develop your custom element,
and finish by installing it in HELIO. Perfect for getting your hands dirty and
understanding how extension development actually works.
