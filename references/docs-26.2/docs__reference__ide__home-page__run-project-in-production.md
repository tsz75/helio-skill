
# Run a Project in Production Mode
After you have completed your project, you will probably want to run it in
production mode. This means no placeholders, only live PLC data is used and
displayed.
- Open the Home Page
Find the HMI you would like to run.
- Press `Run`
…to execute the HMI in the active browser tab
←
→
- Choose a `Copy URL`
If you would like to run the HMI in another tab or on another device,
open the action menu and choose the `Copy URL` option.
