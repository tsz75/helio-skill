
# Restore HELIO From a Backup
Restoring is the reverse of Backup HELIO:
put your previously backed-up HELIO Data Directory back in place.

## Restore the Data Directory
- Stop the HELIO Runtime.
- Locate your Data Directory for your operating system.
- Replace it with your backed-up copy.
- Start HELIO again.
