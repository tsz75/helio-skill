
# PLC Connection

## Types
OPC UA Connection
With the OPC UA Connection, you can connect HELIO to PLCs that comply with
the established OPC UA standard.
NOA Connection
The NOA Connection allows you to connect HELIO to PLCs and products that
support the NOA-Protocol for example:
- Embedded control C6 COMPACT
3
HELIO MQTT Connection
With the MQTT Connection, you can connect HELIO to PLCs that comply with the
established MQTT standard.
