
# Axis Control Widget
Use the `Axis Control Widget` to embed
Single Axis and
Dual Axis right into a
Dashboard Page or a
Dashboard Widget. If there is not enough space to
display the control within the widget, an
Axis Control will serve as a fallback.

## Properties

### Initial Mode
Specify which mode of interaction should be selected by default for the axis
controls. Could be `Jog` or `Step`.
Display Condition

#### Condition
The
Display Condition
controls the visibility of an element or page for the current user. The condition can be set to different types of
Dynamic Property
– as long as the the type returns
true
or
false
you're good to go.
