
# Enumerations

## About
An enumeration allows you to define a set of values that a variable can be
assigned to. This feature is useful for restricting the possible values that a
variable can take.
In addition, you can use enumerations to define human-readable options for
Integer or
String that are used to store a
selected value from a group of possible options. When doing so HELIO automatically
creates Translation Keys
which you can then configure within the Translation Manager.
