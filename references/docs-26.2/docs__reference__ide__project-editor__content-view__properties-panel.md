
# Properties Panel
The `Properties Panel` allows you to adjust all the properties of the
Element that is currently selected in the
HMI Content Tree and the
HMI Preview Panel.

## Anatomy
- Header displaying the type and name of the currently selected
Element.
- A `Property Group` (in this case `General`) is a collection of related
properties that can be collapsed.
- A property of the currently selected
Element. In this case it is the `Icon` property of
the page.
