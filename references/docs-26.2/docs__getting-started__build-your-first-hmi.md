
# Build Your First HELIO HMI Using the HMI-Driven Approach

### This Tutorial Covers
- Adding Pages and Elements
- Choosing different Page Types
- Previewing your HMI

## What Type of HMI Are You Building?
We will create a user interface for a machine equipped with a fixed touch
panel. Our engineering team has some ideas, but we don't have a specific
data model or the finished PLC code yet.
So our task is to create a prototype that can be easily connected to the
PLC once it is in a testable state.
We refer to this as the **»HMI-Driven Approach«.**
