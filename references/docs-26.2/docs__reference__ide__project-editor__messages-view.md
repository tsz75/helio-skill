
# Messages View

## About
The `Messages View` is used to configure messages that inform operators about
important machine events or state changes.

## Sections

### Message Types

## 
Use it to define the different types of messages and to enter the detailed
content for each of them.

### Message Triggers

## 
Use it to set up rules that trigger the various message types.
