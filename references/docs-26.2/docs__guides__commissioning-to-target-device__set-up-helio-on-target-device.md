
# Set Up and Activate HELIO on the Target Device
Before executing your HELIO project on a target device, you must install the
HELIO Runtime environment.
Your development PC is used by you and your team to build and work on
different projects, so it uses the full HELIO Development License.
In contrast, your target devices should be optimized for minimal resource
usage. They should only use lightweight HELIO Runtime Licenses to execute a
single project.
This step will walk you through installing the runtime, configuring it for
your target hardware, and activating the appropriate licenses.

### HELIO Standalone or HELIO Edition?
These first steps are necessary if you are running `HELIO Standalone` and
setting up your target device manually.
However, if you are deploying for a particular industrial ecosystem, such as
ctrlX or NOA, then you are effectively using a `HELIO Edition`.
In this case, you can simply follow the Download HELIO guide
for your ecosystem.
- Purchase a Runtime License
Head over to the Pricing Page of the HELIO website.
- Locate the `Contact` section and get in touch with our Sales Team.
- Together we'll find the right Runtime License size and approach for purchasing your license volume.
- Download, Start, and Activate HELIO
Follow the steps defined on these pages to download, start and activate
your target device:
- Download HELIO
- Start HELIO
- Secure the IDE User Credentials

### Secure Your Target Environment
Given that this device will be used in production, it is essential to
establish a secure environment from the beginning.
Therefore, it is essential to remove the default IDE user and create a
new user with a strong password using the IDE Authentication.
Mission accomplished!
You’ve setup HELIO on your target device. Now it's time to package our
project and deploy it.
