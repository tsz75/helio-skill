
# Backup HELIO
HELIO stores all of its data in a single HELIO Data Directory. To back up
HELIO, it's enough to back up this one directory.

## How To Back Up
- Locate the Data Directory based on your operating system.
- Copy or archive the whole directory to a safe location (external drive, network share, or your regular backup solution).

### Back Up While HELIO Is Not Running
To avoid backing up a partially written state, stop the HELIO Runtime before
copying the directory.

## When to Back Up
- **Before upgrading** – see Before the Upgrade for the full upgrade checklist.
- **Before making any important configuration changes** you might want to undo.
- **Regularly, when running on target devices** in production.
