
# Commissioning to Target Device
You and your team have developed your project to the point that it can be
transferred and deployed to a target device for production use under
real-world conditions.

### Tip: Deploy Early and Deploy Often
You should definitely do this as early as possible in your project
lifecycle! When you take projects onto a target device, you often learn
surprising things about hardware performance and operating system specialties.
You'll want to tackle these with a clear head — not when everyone's rushing to
finish for a deadline.
So deploy early and deploy often! The guides in this section will help you do
just that.
Commissioning or Deployment?
In software development, this process is typically called "deployment," while
in industrial automation it's known as "commissioning." Both terms refer to
the same fundamental process: taking your application from the development
environment and installing it on the target hardware for production use.
Throughout this documentation, we use both terms interchangeably to
accommodate different professional backgrounds.
