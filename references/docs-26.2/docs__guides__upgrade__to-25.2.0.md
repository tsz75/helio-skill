
# Upgrade HELIO to 25.2.0
HELIO 25.2.0 awaits! Let's make this
upgrade smooth and simple.

### Before the Upgrade
Before beginning any version-specific upgrade steps, be sure to follow all the
steps in the Before the Upgrade guide.

## Import the Latest Resources
While `HELIO 25.2.0` does not introduce breaking changes, it comes with new
features, templates and translations that we need to bring into our
Multiple Runtime Versions.
- Import New Translations
`HELIO 25.2.0` introduces new features, including the Audit Trail. These
features come with new pages and elements. Naturally, these elements
include new translations. Follow these steps to import the latest
translations into your existing HELIO runtime:
- `Download HELIO-25.2.0-Translations.json`
- Import this file using the Translation Manager
- Note Renamed Message Triggers
This note is intended for those who have been using the `Dynamic Message` trigger
within existing projects.
In `HELIO 25.2.0`, we renamed the existing `Dynamic Message` trigger to
`JSON Object` trigger. They work the same way they did in `HELIO       25.1.1`, they are just available under a different name.
Mission accomplished!
You've successfully upgraded to `HELIO 25.2.0`. Now, have fun with its new features.
Happy HMI Engineering!
