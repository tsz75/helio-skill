
# Upgrade HELIO
Staying up to date is key when creating HMIs for critical industrial equipment,
complex manufacturing systems, or innovative products that serve customers for
years. You need security updates and new features to tackle ever-growing
complexity.
We designed HELIO for teams developing ambitious HMIs built to last. Longevity,
and maintainability are one of our primary objectives, so we try to make
upgrading as easy as possible. This way, you and your team can build
long-lasting HMIs while consistently upgrading to the latest version.
