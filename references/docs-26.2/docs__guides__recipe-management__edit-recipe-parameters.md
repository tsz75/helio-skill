
# Edit Recipe Parameters

### New This Feature Was Added In HELIO  26.2.0
Editing recipes is one of the most role-dependent tasks in machine
operation: a machine builder may need full access to hundreds of
parameters, while an operator on the shop floor needs guidance and
clarity on just the few that matter.
You've already learned how to edit parameters live on the PLC and save
them as a recipe with Save as Recipe Action in
Define And Save Recipes.
This section covers the opposite direction — editing values that are
already stored in a recipe, without touching the PLC.
