
# Devices Settings
The `Devices Settings` allow you to control which devices will render your
project in a web browser on the device. You can define generic or very
specific devices to which you can refer within the IDE to preview your project
and make it react to device dimensions.

### Devices
You can configure the following properties for each device:

#### Name
This is the name that will be used to identify the device in the IDE.

#### Display in preview toolbar
The name of your HMI target devices won't be shown by default on the
HMI Preview Panel. If you enable this option, the name
of this device will appear on the button bar. Use it to highlight important
devices within the `HMI Preview Panel`.

#### Description
This information will appear as a tooltip when you move the mouse over the
device in the HMI Preview Panel. Use it to provide extra information
that you or the other people working on this project might find interesting.

#### Preview Dimensions
Define the width and height of the device. Choose from predefined
resolutions like `Full HD` or use the `Custom` option to enter a specific
resolution manually.

#### Width
Enter the width of the device in pixels when `Custom` has been chosen as the `Preview Dimensions`.

#### Width
Enter the height of the device in pixels when `Custom` has been chosen as the `Preview Dimensions`.
