
# Create a New Project
- Open the Home Page…
…and make sure you are signed in.
- Press the `Create New` button…
…at the top of the project list.
- Choose a template
HELIO includes three standard templates to assist you in different situations:
- **Empty HMI**Do you enjoy starting with a blank slate and
carefully adding new features? If that's your thing, then this
template is perfect for you!
- **Playground HMI**Would you like to be inspired and see all
the nice things that HELIO can do?
Go ahead and choose this template.
- **Quickstart HMI**Are you interested in learning about HELIO
and like to complete the Run Your First HMI Tutorial?
Start with this template as a skeleton with a minimal with predefined
HMI data.
- Optional: rename the project
The new project will be created with a default name. You can change the name
using the Project Menu.
Mission accomplished!
You successfully created a project! Now go ahead and make it yours using the Project Editor.
