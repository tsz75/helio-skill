
# General Settings
Use the `General Settings` to specify the most basic meta data of your project.

### Project Settings

#### Description
This description will be shown on the
Home Page, which helps your fellow
team members get a handle on what this project is all about.

### Personalization Defaults

#### Zoom
Set the default zoom level for all clients. However, each client can adjust
the zoom level individually at runtime by opening the built-in HELIO
Personalization dialog using the Show Dialog Action.

### Customize Preview
Customizing the project preview on the
Home Page is especially helpful when you're
juggling multiple projects at once. It makes it easy to quickly find the one
you're currently working on.

#### Image
Upload an image that will be shown on the
Home Page.

#### Icon & Color
Choose an icon and color that will be shown on the
Home Page.
