
# Before the Upgrade
Any update should be carefully planned and executed. Although HELIO aims to
ensure a safe upgrade process for you and your team, it's crucial to take a
moment to consider your approach, especially when upgrading HELIO on a target
device.
- Understand HELIO's Data Directory
The HELIO Data Directory is an important aspect
when upgrading your HELIO Runtime.
If you haven't done so already, make sure to revisit
its documentation page.
Let's recap:
- HELIO stores all of its data in the HELIO Data Directory.
- HELIO automatically organizes this directory by creating folders for
each version of HELIO that has been started on this machine.
- When you first launch a new version of the HELIO runtime on your
machine, HELIO will copy all of the data from the previous version and
safely upgrade your projects to the new version in a new folder.

### HELIO's Got Your Back!
If an upgrade should ever fail and destroy a project, you can instantly
go back to the previous
HELIO Runtime version and keep working with the previous
versions of your projects.
- Optional: Backup the Data Directory
If you would like to play it absolutely safe, then you can even take a
backup of the whole Data Directory before
proceeding with any further steps. Doing so means that you can always
bring back the old version of your data directory and start from
scratch.
See Backup HELIO for how to do this.
- Keep Your Existing HELIO Runtime Directory
HELIO does not require an installation. That's why it is possible to keep
multiple HELIO Runtime versions around on the same machine. See
Multiple Runtime Versions for more details on how to
best organize this.
- Download & Start the New HELIO Runtime
Time to grab new version of the runtime:
- Head over to the Download HELIO page and download the latest
version.
- Follow the instructions on the Start HELIO
to launch the new HELIO Runtime version.
