
# Import Recipes Action
Import multiple recipes of a given type previously exported using the the
Export Recipes Action. When this action is executed, the
browser opens a file chooser that requires the user to select a CSV file from
their file system.

## Example
Specify which recipe type you want to import. Since recipes
are different in terms of the parameters they contain, they can't be
combined into one CSV file.

## Format
See the Export Recipes Action for the required format.
