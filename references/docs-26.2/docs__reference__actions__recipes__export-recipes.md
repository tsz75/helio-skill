
# Export Recipes Action
Create and download a CSV file of all recipes of a given type to back up or
to migrate recipes to a different machine using the Import Recipes Action.

## Example
Specify which recipe type you want to export. Since recipes
are different in terms of the parameters they contain, they can't be
combined into one CSV file.

## Export Format
This is an example of a recipe type called `Product Recipe` that contains two parameters.
```
name@Product Recipe [45Gt_UsbQ22T4Iz9gHPbhg],created_at,created_by,modified_at,modified_by, [3xD0U9XPRrK12D1oD_6dcw], [_DBDfqjnS5SXmQ-vQor_7w]
Product ABC,2025-07-18T16:10:35.424796Z,,,,true,1
Product DEF,2025-07-18T16:10:55.955131Z,,,,false,1
```
