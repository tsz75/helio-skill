
# Recipes View

## About
Use the `Recipes View` to define your machine's `Recipe Types` and add
ingredients to those recipes using the data model you have setup in the
Data View.
- List of all recipe types.
- Use the `+` button to create new recipe types.
- List of all recipe parameters for the selected recipe type.
- Use the `+` button to add new parameters to the recipe type.Improved This Feature Was Improved In HELIO  26.2.0Drag a whole directory from the Data View onto
a recipe type to add all of its variables at once, instead of
adding them one by one.
- Set the restrictions for the recipe type.
