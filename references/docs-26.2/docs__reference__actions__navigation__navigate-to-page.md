
# Navigate to Page Action

## About
This action enables operators to navigate away from the current Page to a
different page within the HMI.
For instance, this action would allow the HMI to transition from the current
page to the `Dashboard` page.
The navigation triggered by this action will be added to the history stack
of your browser. Therefore, using the back button will take you back to
the original page.
