
# HELIO Data Layer
HELIO is equipped with a data layer that allows you to connect to different
types of data sources and abstract their data in a unified way within your
project.
This architecture also allows you to set up your data model in advance, so you
can start shaping the model of your HMI even before a PLC is ready.
