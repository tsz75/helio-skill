
# Switch
Similar to the If Condition, the `Switch` lets you adjust a
property's value based on rules you define.
First, define an `Expression` that HELIO will evaluate.
- HELIO compares the value of that expression to different cases.
- Set up different cases for the specific values that will be assigned to the property.
Check out this example! It changes the icon of an element based on the state
of a Data Variable (Dynamic Property).
