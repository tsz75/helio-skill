
# What is the difference between Runtime and Developer License?
The `Developer License` is required for your development machine while you're
creating your HMIs and it has no limitations. The `Runtime Licenses` are needed
for each target device where you plan to deploy your project. A `Runtime License` can be
customized in size and capabilities to suit your specific use case perfectly.
Find out more about the differences between these types of licenses:
|  | Developer License | Runtime Licenses |
| **Device** | Development PCs of each team member that participates in the HMI engineering process by editing and contributing to HELIO HMI projects using this device | Every target device that executes the HELIO Runtime to provide an HMI |
| **Subscription** | Yearly (No auto-renewal) | None |
| **HELIO Updates** | All HELIO updates within the subscription period can be installed and used. | By default target devices using a Runtime License are bound to a specific HELIO Version.Purchasing a `Developer License` empowers you to update HELIO on all devices using a `Runtime License`. |
| **Number of Projects** | Unlimited | 1 |
| **Sizeable** | Unlimited | Can be sized according to your use case – from `XS` to `XL`For a full list of prices and limits: Check out https://helio-hmi.com/en/pricing if you want to run HELIO Standalone (not tied to a specific operating system). Check out the HELIO app in the ctrlX Store, if you plan to run the HELIO ctrlX Edition on a ctrlX-powered hardware. |
