
# Fixed-Size Spacer

## About
Adds a fixed space between two elements.

## Properties

### Sizing

#### Spacer Width
Decide if the spacer should be flexible or fixed-size. Flexible spacers
occupy all the available space, whereas fixed spacers utilize a specified
amount of pixels.

#### Fixed Width
Select the width of the spacer.
Display Condition

#### Condition
The
Display Condition
controls the visibility of an element or page for the current user. The condition can be set to different types of
Dynamic Property
– as long as the the type returns
true
or
false
you're good to go.
