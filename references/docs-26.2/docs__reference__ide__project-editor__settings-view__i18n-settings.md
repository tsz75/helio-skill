
# Internationalization Settings
The `Internationalization Settings` allow you to control everything needed to make
your project available in different languages and markets.

### Languages
Tell HELIO which languages you want to translate this project into. Also, be
sure to set a default language that will be used when operators have not yet
set a preference.

### Unit Conversions
Define the unit conversions that will be available to operators in this
device. For each conversion you define a source and target unit. HELIO will
also suggest common conversions for you (e.g. `ft` → `mt`) so you don't have
to care about the math behind them. Use the
Unit Switch element to easily switch between
multiple units.
