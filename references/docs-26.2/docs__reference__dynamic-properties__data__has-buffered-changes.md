
# Has Buffered Changes

## About
Use the `Has Buffered Changes` property in conjunction with the
Parameter Page if it's configured to buffer all
parameter changes via the `Confirm With Action` option.
This property is particularly useful when you need to disable or enable
buttons that apply or discard those buffered changes.
