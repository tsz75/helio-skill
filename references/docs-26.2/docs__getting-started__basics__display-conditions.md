
# Display Conditions
Every
Page and every
Element in HELIO shares a truly subtle, but very
powerful, superpower: the
Display Condition.
It lets you control whether something is visible to your operators or if it
stays out of the way.
Display conditions can be combined with many
Dynamic Properties in order to make your HMI react
intelligently to its context, without adding complexity. This opens up a lot of
possibilities: Show advanced settings only to logged-in administrators. Hide
elements when screen space is limited. Reveal information exactly when and where
it's needed and nowhere else.
In short: display conditions help you build HMIs that are not just functional,
but aware, focused, and user-friendly.

## Use Cases
Let's take a look at some typical use cases for that to get an idea of what's
possible.

### Restrict Pages to Specific Users
←
→
The most common use case: using conditions to tailor your HMI to specific
user groups.
- Activate the display condition for the page
- Select Restrict To Users
- Only allow signed-in administrators
**Learn more** with the following resources:
- Access Control

### Display Elements Only on Particular Device Sizes
←
→
A method to show complex elements only on larger devices that is often
overlooked. Can also be used in reverse, for example, to hide
data-intensive elements on smaller screens.
- Activate the condition for an element
- Select Device Size
- Choose at least or lager than iPad Landscape.
**Learn more** with the following resources:
- Devices Settings

### Hide Elements or Pages Using Your PLC
←
→
Let your PLC control which pages or elements to show and hide. Useful
for tailoring HMIs to different machine configurations.
- Activate the display condition for the element
- Select Data Variable (Dynamic Property)
- Choose a boolean data variable
**Learn more** with the following resources:
- PLC Connection
- Data Variable Types
- Import Data From Your PLC
