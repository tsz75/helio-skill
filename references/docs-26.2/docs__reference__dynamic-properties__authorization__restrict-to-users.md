
# Restrict To Users

## About
The `Restrict To Users` property gives you the power to say who gets to see what on
your HMI. It tells you if the signed-in HMI User has certain roles. It
returns `true` or `false` based on the roles selected and assigned to the
currently logged-in user.
If you want **limit an element bound to this property to signed-in
users only**, simply check all the roles.
