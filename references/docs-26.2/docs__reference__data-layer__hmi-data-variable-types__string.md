
# String
A `String` is a data type that represents a sequence of characters. It can be used
to store text, symbols, and even numbers in a format that can be easily
manipulated. In HMI programming, strings are often used to store data such as
user input, machine status, and error messages.

## Define a Variable
- Open the Data View
- Right-click any folder in the HMI Data Explorer
- Choose `Add Variable`
- Choose the type  String

## Additional Metadata
- Placeholders for Offline Editing
