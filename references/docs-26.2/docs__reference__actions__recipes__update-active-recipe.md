
# Update Active Recipe
Updates all the parameters of the active recipe with the the values that are
currently loaded in the PLC. If there is no active recipe, the `Create Recipe`
dialog will be opened which allows operators to create a new recipe.

## Properties

### Recipe Type
Choose one of the predefined `Recipe Types` to be updated. See the
Recipe Management guide to learn more about recipe types.
