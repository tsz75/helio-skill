
# HELIO IDE
The HELIO Integrated Development Environment (IDE) is the graphical environment
where users design and test their HMIs. It features a visual interface with
drag-and-drop, a library of elements, icons, and real-time testing.
No coding skills are required to create
sophisticated HMIs.
