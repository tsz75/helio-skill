
# HELIO MQTT Connection

## About
Use the HELIO MQTT Connection to connect HELIO to PLCs that comply with the
established MQTT standard.

## How to communicate with HELIO using MQTT
If you want to connect your PLC to HELIO using MQTT, you currently need to
follow the HELIO PLC Protocol over MQTT. For more detailed information on
connecting your PLC to HELIO using MQTT, you can refer to the protocol
documentation:
- HELIO PLC Protocol over MQTT v1.1
