
# Keyboard Shortcuts (Content View)
HELIO is fully equipped with keyboard shortcuts to make repetitive tasks easier
and to help you complete your project faster.

## HMI Content Tree

#### Navigating the Tree
|  | Windows | Mac | Linux |
| Search Within the Content Tree | / | / | / |

#### Adding New Elements
|  | Windows | Mac | Linux |
| Add New Element | Ctrl + E | command + E | Ctrl + E |

#### Manipulating the Selected Element
|  | Windows | Mac | Linux |
| Rename Element | Enter | Enter | Enter |
| Duplicate Element | Ctrl + D | command + D | Ctrl + D |
| Move Element Up | Ctrl + ↑ | command + ↑ | Ctrl + ↑ |
| Move Element Down | Ctrl + ↓ | command + ↓ | Ctrl + ↓ |
| Cut Element | Ctrl + X | command + X | Ctrl + X |
| Copy Element | Ctrl + C | command + C | Ctrl + C |
| Paste Element | Ctrl + V | command + V | Ctrl + V |
| Remove Element | ⌫ Backspace or ⌦ Delete | ⌫ Backspace or ⌦ Delete | ⌫ Backspace or ⌦ Delete |

## HMI Preview Panel
**Toggle Preview Mode: Quickly Switch Between Editing and Testing**
While editing your HMI in the Content View, press the
following combination of keys to quickly switch between the different Data
Connection Modes.
|  | Windows | Mac | Linux |
| Toggle Editor Mode | Ctrl + ⇧ + Space | control + ⇧ + Space | Ctrl + ⇧ + Space |
