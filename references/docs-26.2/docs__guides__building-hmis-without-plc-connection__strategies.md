
# Strategies for Defining HMI Data
There are two strategies for defining HMI Data when constructing and
engineering HMIs:

### HMI First
**How?**
First, set up your `HMI Data`. Then, link that data to the PLC.
**When?**
- The PLC and its data model have not been defined, yet.
- You need shape this data model together with the PLC experts of your team. HELIO
can then be a communication tool for quickly sketching out the data model and
using it with the help of the
inside the Content View.

### PLC First
**How?**
Import and augment existing `PLC Data`.
**When?**
- A solid data model for the PLC already exists.
- You don't need to adjust your HMI model to reach desired states and outcomes
within your HMI.
If you want to learn more about the `PLC First` strategy, you can refer to the
Connect & Control Your PLC guide.
However, the
following steps focus on the `HMI First` strategy and guide you through the
process of developing an HMI when the PLC and its data model have not yet been
finalized and set up. Let's get on with it!
