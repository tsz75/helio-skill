
# HELIO Editions
HELIO's vision is to empower cross-functional teams to work together to create
better HMIs with as much flexibility and autonomy as possible. That's why the
HELIO Runtime is compatible with Windows, Linux and MacOS by
default.
In addition to these general-purpose operating systems, new modular platforms are
emerging that go a step further, offering more industry-specific functionality
and fine-grained control of real-time capabilities.
For this reason, HELIO is available for selected platforms as so-called editions
which can be seamlessly integrated into the respective ecosystems.
