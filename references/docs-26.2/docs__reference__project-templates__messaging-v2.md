
# Messaging v2
HELIO 24.2 takes the simplicity and flexibility of messaging and alarming
to the next level by combining several new features into a unified
solution. Check out the this template to learn
how to set up the different aspects.

## Using the Template
Use the `Create New` button on the
Home Page of the
HELIO IDE and you will be asked to choose a template for your
project.
